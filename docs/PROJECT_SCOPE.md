# RailSearch — Project Scope

## Project objective

RailSearch is a portfolio-grade product analytics and data science project designed to investigate the end-to-end digital rail booking journey:

Search → Results → Selection → Checkout → Booking

The project focuses on identifying customer friction, explaining conversion changes, surfacing commercial opportunities and building reusable analytical tooling.

## Business problems

The project will answer questions including:

- Why has search-to-book conversion changed?
- Which searches return no journey results?
- Where do customers abandon the booking funnel?
- Which devices, routes and customer segments experience the greatest friction?
- What drives checkout and payment failures?
- Which issues create the greatest commercial impact?
- Which sessions have the highest or lowest probability of converting?
- Can abnormal conversion deterioration be detected automatically?
- Which interventions should Product, Commercial and Engineering teams prioritise?

## Data policy

No proprietary Trainline customer data is used.

Customer journey and commerce events will be synthetically generated using documented assumptions.

Where practical, public UK rail reference data will be used to provide realistic station and network context.

Synthetic data will always be clearly labelled as synthetic in project documentation.
