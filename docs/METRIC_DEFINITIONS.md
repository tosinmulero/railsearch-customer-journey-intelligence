# RailSearch — Metric Definitions

## Search-to-book conversion rate

Completed bookings / eligible searches

## Session conversion rate

Sessions resulting in at least one completed booking / eligible sessions

## Zero-result rate

Searches returning zero journey options / total searches

## Result-selection rate

Searches where a journey option was selected / searches with at least one result

## Checkout-start rate

Sessions entering checkout / eligible sessions

## Checkout completion rate

Successfully completed checkouts / checkout attempts

## Checkout error rate

Checkout attempts containing a checkout error / checkout attempts

## Payment failure rate

Payment attempts that failed / payment attempts

## Funnel abandonment rate

Eligible sessions that exit before successful booking / eligible sessions

## Average order value

Total booking revenue / completed bookings

## Revenue per session

Total booking revenue / eligible sessions

## Revenue at risk

Estimated commercial value associated with sessions affected by identified friction.

This is an analytical estimate and must always be labelled as such.
